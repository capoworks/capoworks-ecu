# Source file attribution

For every future new first-party source file in this repository, including tests and developer scripts, attribute Giacomo di Ciocco using comment syntax and the conventions appropriate to the language. Use the actual contribution year; never invent dates.

- For newly original C/C++ files, use the Doxygen `@file` and `@author Giacomo di Ciocco, (C) <year>` convention.
- For derived or adapted files, preserve all upstream author, license, and provenance notices. Add a scoped note describing the Capoworks adaptations or modifications and attribute Giacomo di Ciocco for those changes.
- Do not add author attribution to third-party or generated files, or to formats that do not support comments (for example, JSON).
- Keep existing licenses unchanged.

This is a project-scoped preference.
